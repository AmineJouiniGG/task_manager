# Task Manager

Production-style web app: **Frontend → REST API → PostgreSQL**.

Project to learn Cloud & DevOps by building and deploying end to end.

---

## Stack decisions

| Layer | Choice | Why |
|---|---|---|
| Backend | **FastAPI (Python)** | Fast to write, automatic OpenAPI docs, async, easy to containerize. |
| Database | **PostgreSQL** | Production database you will run on Linux, Docker, AWS, and Kubernetes. |
| Frontend | **React (Vite)** | Separate frontend service: CORS, env vars, multi-stage Docker, nginx static hosting. |
| Auth | **JWT** | Stateless auth that works the same on a VM, in Docker, and behind a load balancer. |

---

## Architecture

```
Browser (React)
    │  HTTP + JWT
    ▼
FastAPI REST API
    │
    ▼
PostgreSQL
```

- Users register and log in. The API returns a JWT.
- All `/tasks` routes require `Authorization: Bearer <token>`.
- Each user only sees and changes **their own** tasks.

---

## API Endpoints

| Method | Route | Auth | Description |
|---|---|---|---|
| POST | `/auth/register` | No | Create a user (`username`, `password`). Returns user id + username. |
| POST | `/auth/login` | No | Validate credentials. Returns a JWT access token. |
| GET | `/tasks` | JWT | List the current user's tasks. |
| POST | `/tasks` | JWT | Create a task (`title`, optional `description`). |
| PUT | `/tasks/{id}` | JWT | Update a task (title, description, completed). |
| DELETE | `/tasks/{id}` | JWT | Delete a task. |

Standard responses:

- `401` missing/invalid token
- `403` task belongs to another user
- `404` task not found
- `409` username already taken

## Database Schema

### users

| Column | Type | Notes |
|---|---|---|
| id | UUID | Primary key, generated by the database |
| username | VARCHAR(50) | Unique, required |
| password_hash | VARCHAR(255) | Hashed with bcrypt (never store plain passwords) |
| created_at | TIMESTAMPTZ | Default `now()` |

### tasks

| Column | Type | Notes |
|---|---|---|
| id | UUID | Primary key, generated by the database |
| user_id | UUID | Foreign key → `users.id`, `ON DELETE CASCADE` |
| title | VARCHAR(200) | Required |
| description | TEXT | Optional |
| completed | BOOLEAN | Default `false` |
| created_at | TIMESTAMPTZ | Default `now()` |
| updated_at | TIMESTAMPTZ | Updated on every change |

- [ ] FastAPI project: register, login, JWT middleware
- [ ] PostgreSQL schema + migrations
- [ ] CRUD for tasks, scoped to the logged-in user
- [ ] React UI: login/register + task list (create, complete, delete)
- [ ] Run locally: API + Postgres + frontend

### Phase 2: Linux deployment

- [ ] Provision a Linux VM
- [ ] Install Python, Node, Nginx, PostgreSQL
- [ ] Run the API with systemd (or similar)
- [ ] Serve the React build with Nginx
- [ ] Reverse proxy `/api` to FastAPI

### Phase 3: Docker

- [ ] Dockerfile for the API
- [ ] Multi-stage Dockerfile for the frontend
- [ ] `docker-compose.yml`: api + frontend + postgres
- [ ] One command to run the whole stack

- [ ] Push images to a registry

- [ ] Describe AWS resources in Terraform

### Phase 6: CI/CD

- [ ] Pipeline: lint, test, build images
